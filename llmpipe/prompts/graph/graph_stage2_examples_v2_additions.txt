EXAMPLE — an adjective + noun class decomposes the same way in every unit (§7b.3)

Input (Stage 1): "If something is a heavy vehicle, then it needs a special
                  licence."
                 "Large trucks are heavy vehicles."
                 "A tow truck is a large kind of truck."

WRONG
 ["@id","S1",["holds","W0",["forall","X",["implies",["isa","heavy_vehicle","X"],
     ["isa","needs_a_special_licence","X"]]]]],
 ["@id","S2",["holds","W0",["forall","X",["implies",
     ["and",["isa","truck","X"],["isa","large_for_a_truck","X"]],
     ["and",["isa","vehicle","X"],["isa","heavy_for_a_vehicle","X"]]]]]],
 ["@id","S3",["holds","W0",["forall","X",["implies",["isa","tow_truck","X"],
     ["and",["isa","truck","X"],["isa","large_for_a_truck","X"]]]]]]

RIGHT
 ["@id","S1",["holds","W0",["forall","X",["implies",
     ["and",["isa","vehicle","X"],["isa","heavy","X"]],
     ["isa","needs_a_special_licence","X"]]]]],
 ["@id","S2",["holds","W0",["forall","X",["implies",
     ["and",["isa","truck","X"],["isa","large","X"]],
     ["and",["isa","vehicle","X"],["isa","heavy","X"]]]]]],
 ["@id","S3",["holds","W0",["forall","X",["implies",["isa","tow_truck","X"],
     ["and",["isa","truck","X"],["isa","large","X"]]]]]]

(In the wrong output S1 has the class "heavy_vehicle" as one name and S2 has
it as "vehicle" plus "heavy_for_a_vehicle"; the chain tow truck -> large
truck -> heavy vehicle -> special licence is cut between S2 and S1. Choose
one way to write an adjective + noun class and use it in every unit. Here the
passage compares nothing across classes, so the adjectives are bare.)

EXAMPLE — the comparison class must not split one adjective into two names (§7b.6)

Input (Stage 1): "If a chef prepares a dish, the chef is skilled and the dish
                  is well-presented."
                 "Chef Sam 1 cooked a special recipe 2."
                 "Is Chef Sam 1 skilled and the special recipe 2
                  well-presented?"

WRONG
 ["@id","S1",... ["isa","skilled_for_a_chef","X"] ... ["isa","well-presented_for_a_dish","Y"] ...],
 ["@id","S3",["question",["and",["isa","skilled_for_a_person","Chef Sam 1"],
     ["isa","well-presented_for_a_recipe","recipe 2"]]]]

RIGHT
 ["@id","S1",... ["isa","skilled","X"] ... ["isa","well_presented","Y"] ...],
 ["@id","S3",["question",["and",["isa","skilled","Chef Sam 1"],
     ["isa","well_presented","recipe 2"]]]]

(The passage compares nothing: "skilled" means the same for a chef and for a
person, "well-presented" the same for a dish and for a recipe. Four names for
two adjectives make the question unreachable. Hyphens become underscores.
Write `_for_a_<class>` only where the passage itself contrasts the class:
"John is a big mouse" against "big for an elephant".)

EXAMPLE — "normally" only where the unit's own words hedge (§7b.7)

Input (Stage 1): "If people complain often about annoying siblings, then they
                  have siblings who were born together."   (type normal_rule,
                  confidence 0.95)
                 "Generally, plants that grow in high altitude areas are
                  robust against cold."   (type normal_rule, confidence 0.98)
                 "However, there is at least one plant that grows in high
                  altitude areas that is not robust against cold."

WRONG
 ["@id","S1",["and",["holds","W0",["forall","X",["implies",
     ["and",["isa","person","X"],["isa","complains_often_about_annoying_siblings","X"]],
     ["normally",["exists","Y",["and",["isa","sibling","Y"],["born_together","X","Y"]]]]]]],
   ["@p","S1",0.95]]]

RIGHT
 ["@id","S1",["holds","W0",["forall","X",["implies",
     ["and",["isa","person","X"],["isa","complains_often_about_annoying_siblings","X"]],
     ["exists","Y",["and",["isa","sibling","Y"],["born_together","X","Y"]]]]]]],
 ["@id","S2",["and",["holds","W0",["forall","X",["implies",
     ["and",["isa","plant","X"],["grows_in","X","high_altitude_areas"]],
     ["normally",["isa","robust_against_cold","X"]]]]],
   ["@p","S2",0.98]]],
 ["@id","S3",["holds","W0",["exists","X",["and",["isa","plant","X"],
     ["grows_in","X","high_altitude_areas"],["not",["isa","robust_against_cold","X"]]]]]]

(S1 is an "If ... then ..." with no hedge word: it is strict, whatever the
Stage-1 unit type says. S2 says "Generally": that is the hedge, so "normally"
with the confidence. S3 is the stated exception: an existential, no
"normally", and it uses S2's names — "high_altitude_areas", not a new
"high_altitudes". Hedge words: generally, usually, typically, normally, tend
to, often, most, likely, may, might, seems, suggests.)

EXAMPLE — a conditional question keeps its two sides as written (§7b.8)

Input (Stage 1): "Can we conclude: if a Ruby is not high-quality, then a
                  Diamond is not valuable?"

WRONG
 ["@id","S8",["question",["forall","X",["implies",
     ["and",["isa","ruby","X"],["not",["isa","high_quality","X"]]],
     ["forall","Y",["implies",
        ["and",["isa","diamond","Y"],["not",["isa","valuable","Y"]]],
        ["not",["isa","valuable","Y"]]]]]]]]

RIGHT
 ["@id","S8",["question",["implies",
     ["forall","X",["implies",["isa","ruby","X"],["not",["isa","high_quality","X"]]]],
     ["forall","Y",["implies",["isa","diamond","Y"],["not",["isa","valuable","Y"]]]]]]]

(The wrong question puts "not valuable" into its own antecedent, so it is true
of anything and proves True from an empty passage. The antecedent is what the
question supposes; the consequent is what it asks; neither repeats the other.
A conditional question is ["question",["implies",A,B]], never an ["ask",...].)

EXAMPLE — a plural in an argument slot is the same class as its singular (§7b.3, §7b.4)

Input (Stage 1): "Solar cells convert solar energy into electrical energy."
                 "Household appliances are a kind of electric device."
                 "Is it true that the energy absorbed by solar cells will be
                  used on powering household appliances?"

WRONG
 ["@id","S2",["holds","W0",["forall","X",["implies",["isa","solar_cell","X"],
     ["converts_into","X","electrical_energy"]]]]],
 ["@id","S3",["holds","W0",["forall","X",["implies",["isa","household_appliance","X"],
     ["isa","electric_device","X"]]]]],
 ["@id","S4",["question",["forall","X",["implies",
     ["and",["isa","energy","X"],["absorbed_by","X","solar_cells"]],
     ["normally",["used_to_power","X","household_appliances"]]]]]]

RIGHT
 ["@id","S4",["question",["forall","X",["implies",
     ["and",["isa","energy","X"],["exists","C",["and",["isa","solar_cell","C"],["absorbed_by","X","C"]]]],
     ["normally",["exists","A",["and",["isa","household_appliance","A"],["used_to_power","X","A"]]]]]]]]

(The passage made "solar cell" and "household appliance" classes. The question
must not turn them into the kind constants "solar_cells" and
"household_appliances": nothing connects a constant to a class. Where the
passage has a class, the question quantifies over it.)

A logic pipeline could not answer one reasoning problem. An earlier stage
proposed which words and expressions to connect, and code then built every rule
those proposals allow. That is the list below. It is mechanical: the code fills
in missing pieces, tries both directions, and varies the guard, so most of these
rules are wrong, redundant, or trivially true.

Your job is to say which ones are worth judging.

WHAT EACH LINE SHOWS

    F3  IF isa(communication, V1) THEN normally isa(sharing, V1)
        from: "The radio shares the weather report."
        target G4 (supply), forward, operator nominalization
        model named: O2, O7        code added: guard isa(activity, V1)
        warning: an identification was invented — `X` of O2 with S1/Y

  * the complete rule, in full, with nothing elided;
  * the source phrases the pieces came from;
  * which expression it aims at, and whether that expression is one the prover
    needs in order to SUPPLY the question's claim or to CONTRADICT it;
  * the direction: forward is source to target, reverse is target to source;
  * the operator family that produced it;
  * which parts an earlier model named, and which code added by itself —
    a slot it filled, a guard it supplied, a direction it flipped, a conclusion
    predicate it substituted, or a generalisation it made;
  * a warning when code INVENTED an identification, that is, decided that a term
    in one sentence and a term in another are the same thing. Nobody has checked
    that yet.

WHAT TO PREFER

  * a rule that connects an expression the English plainly supports with the
    shape the logic actually uses, where you can point at the sentence;
  * a rule whose pieces the earlier model named, over one code assembled alone;
  * a rule whose guard is the restriction that makes it true, rather than one
    that merely narrows it to this problem;
  * both directions of a genuine correspondence, when both are defensible.

WHAT TO AVOID

  * a rule that restates something the passage already says outright — it adds
    nothing to what the prover already has;
  * a rule that holds only because a constant was substituted for a variable;
  * a rule resting on an invented identification when a sibling rule with the
    same content does not;
  * near-duplicates: if several rules differ only in a guard that changes
    nothing, keep the clearest one and let the others go.

WHAT YOUR CHOICE MEANS

Your choice is PRIORITIZATION ONLY. The rules you pick are passed to a separate
semantic judge, which decides whether each one may be believed and can refuse
all of them. Picking a rule is not asserting it, and nothing you pick is added
to the problem by your choosing it. Choosing a rule that is later rejected costs
one judgement; leaving out the only usable rule costs everything downstream.

You have no information about the correct answer, and nothing here tells you
one. Do not try to work out what the answer should be and pick rules that would
produce it.

HOW TO ANSWER

Explain your reasoning in ordinary prose, as much or as little as you need.
Then end with exactly one line, and nothing after it:

At most twelve ids, best first. Use the ids exactly as they are printed. Only
that final line is read.
